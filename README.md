# Rutinas de Buena Salud

## 1. Nombre del proyecto

**Rutinas de Buena Salud**

## 2. Descripción breve del proyecto

Este proyecto consiste en desarrollar una aplicación que promueva hábitos saludables mediante rutinas diarias que contribuyan al bienestar físico y mental. Permitirá a los usuarios organizar actividades como realizar ejercicios, beber suficiente agua, mantener una alimentación equilibrada y descansar adecuadamente.

## 3. Objetivo del proyecto

Desarrollar una aplicación que facilite la organización y el seguimiento de rutinas saludables, motivando a los usuarios a mejorar sus hábitos diarios y mantener un estilo de vida más saludable.

## 4. Herramientas utilizadas

* **Visual Studio:** entorno de desarrollo para crear la aplicación.
* **C# :** lenguaje de programación utilizado para la lógica de la aplicación.
* **.NET MAUI:** framework utilizado para desarrollar la interfaz y la aplicación.
* **XAML:** lenguaje de marcado utilizado para diseñar las interfaces gráficas.
* **Git y GitHub:** herramientas para gestionar las versiones del proyecto y colaborar durante el desarrollo.

Posteriormente, los cambios se integrarán en la rama principal una vez revisados.
